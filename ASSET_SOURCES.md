# Project image reference

The permanent image reference for this portfolio is the user-supplied [Google Drive project folder](https://drive.google.com/drive/folders/16XhClGKEbAALlbU8IAnWuAUaCAaIvfFB).

Use its original photographs and film stills for future replacements. Keep the current taupe/charcoal palette and layout unless requested otherwise. Do not use AI-generated enhancements: the user stopped that work.

The [portfolio slide deck](https://docs.google.com/presentation/d/1uKTbhodd8fXYkv_MReY_IrLt5BK_GFo-kfouUajDl9E/edit) remains the main reference for biographies, project descriptions, and credits. Folder names alone do not establish new project credits.

Store web-ready copies in `assets/`; preserve original compositions and color grading. Keep full-resolution source downloads outside the public repository, and document selected source filenames here.

`image-sources.json` records each selected original, source dimensions, export sizes, and any crop. `scripts/prepare_images.py` reproduces the WebP exports with Pillow. All eight photographs currently displayed use these original-source exports, including the hero and footer portrait.

The original World Cup boy still and music project photos come from the deck's full embedded media. The hero is `my photo/IMG_4705.jpg`, the Yaba wall is `yaba/yaba 2.png`, and the Seven Stones close-up is `the wall/٣.png`. No AI enhancement is applied.
